# Networkwalks Cybersecurity Internship – Week 1

## Project: Cybersecurity Testing Lab Setup

This project was completed as part of the Networkwalks Cybersecurity Internship – Week 1.

### Objective
To set up a cybersecurity testing lab environment using VirtualBox and Kali Linux for educational and authorized security testing.

### Tools Used
- Oracle VirtualBox
- Kali Linux
- 7-Zip
- Windows Host Machine

### Lab Network Configuration
- NAT Network: CyberLab
- Network: 10.0.0.0/24
- Gateway: 10.0.0.1
- Kali Linux IP: 10.0.0.2/24
- DHCP: Enabled
- Internet Connectivity: Enabled

### Tasks Completed
1. Installed 7-Zip.
2. Installed Oracle VirtualBox.
3. Created the CyberLab NAT Network.
4. Imported Kali Linux into VirtualBox.
5. Enabled Intel Virtualization Technology.
6. Configured Kali Linux network settings.
7. Assigned Kali Linux IP address 10.0.0.2.
8. Configured the gateway 10.0.0.1.
9. Verified Internet connectivity.
10. Verified DNS connectivity.
11. Captured screenshots of the completed lab setup.
